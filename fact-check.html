Fact check

Every sentence, number and model setting in this app is a row in a ledger that records whether it has been checked, against what, and how. Here is how that works, how far it has got, and what readers have reported.

How facts are checked

The values here are typical for a healthy adult and simplified for teaching. Simplifying is fine; being wrong is not. Each text exists at four reading levels, and a lower level may leave out detail but may never say something the level above contradicts. The text also has to agree with the numbers that drive the animations, and with the other pages.

One row per claim

A script reads every page and lists each string at each reading level, each glossary entry, and each model constant or function as a row in the ledger. When the text or code changes, its row goes back to unchecked, so new content from the nightly build is never silently approved.

The standard

  • Error: wrong or outdated.
  • Misleading: true word by word, but leaves a false picture.
  • Imprecise: needs a range, unit or qualifier.
  • Style: wording only; doesn't hold a page up.

Looked up or from memory

Each approval names its sources and says honestly how they were used. Looked up means the source was opened and read, with a link and a short verbatim quote. From memory means it was recalled, which is weaker evidence. Rows approved before this was recorded show as source not recorded.

Checking the check

Small random samples of approved rows are re-checked, to estimate how often approvals are wrong, and look-up citations are verified by someone other than the original checker. Mistakes are fixed in the app or filed as a fact-check issue.

The full method, the sources and the consistency registry: FACTUAL_CHECK.md.

    Reader reports

    Spotted something wrong?

    On any page, select the words that are wrong and press Report this, or use the Report a problem button in the header. A short form asks what kind of problem it is and what it should say.

    What happens next

    Your report becomes a public GitHub issue with the exact text, where it comes from and a link that reopens the page as you saw it. It is checked against the sources like any other row, then fixed or answered, and the issue is closed.
